# Data Engineer — подготовка к интервью

Статический сайт-хаб для подготовки к собеседованию на позицию **Data Engineer**.
Темы собраны по разделам: типичные вопросы с ответами, примеры SQL/Python-кода, частые ошибки.

## Разделы

| # | Раздел | Тем |
|---|--------|-----|
| 1 | Как проходит интервью | 1 |
| 2 | SQL | 5 |
| 3 | Python | 4 |
| 4 | Spark | 5 |
| 5 | System Design | 5 |

Итого: **20 тем** + каталог.

## Структура

- `index.html` — оболочка с меню, поиском по темам, переключателем темы и прогрессом.
- `catalog.html` — каталог: карточки тем по разделам.
- `*-*.html` — страницы тем (`sql-*`, `python-*`, `spark-*`, `sd-*`) плюс `how-interview.html`.
- `book-style.css` — стили (темы beige/graphite, блоки кода, вопрос-ответ, уровни).
- `book-theme.js` — тема, отметка «освоено», прогресс чтения.

## Особенности

- Светлая и тёмная темы, переключение запоминается.
- Отметка «освоено» по каждой теме и общий прогресс.
- Поиск по темам в меню.
- Метки уровня (Junior / Middle / Senior) и блоки кода с горизонтальной прокруткой.
- Mobile-friendly: выдвижное меню, единая нижняя панель.

## Публикация в интернете (GitHub Pages)

Сайт статический, поэтому публикуется бесплатно за пару минут.

**1. Склонировать репозиторий**

```bash
git clone git@github.com:SergeiTarasovDev/DEInterview.git
cd DEInterview
```

Если SSH-ключ не настроен, используйте HTTPS-ссылку: `https://github.com/SergeiTarasovDev/DEInterview.git`.

**2. Включить GitHub Pages**

- Откройте репозиторий на GitHub → **Settings** → **Pages**.
- **Build and deployment** → Source: **Deploy from a branch**.
- Branch: **main**, папка **/ (root)** → **Save**.
- Репозиторий должен быть **публичным** — на бесплатном тарифе Pages доступны только для публичных репозиториев.

**3. Открыть в любом браузере**

- Через ~1 минуту сайт доступен по адресу `https://sergeitarasovdev.github.io/DEInterview/`.
- Открывается в любом браузере на компьютере, планшете и телефоне — устанавливать ничего не нужно.
- При каждом `git push` в ветку `main` сайт обновляется автоматически.

**Локально без публикации**

Откройте `index.html` двойным кликом — сайт работает и без интернета (внешних зависимостей нет).
